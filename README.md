# ⚜️ TITEN LAKU JAWA
### *Sistem Perhitungan Waktu, Watak, dan Navigasi Irama Siklus Hidup Manusia Jawa*

**A modern, precise, and comprehensive application for calculating traditional Javanese time cycles, grounded in the ancient science of Javanese Titen Laku. Designed by Mario Fahmi Syahrial**

---

## 🌟 Fitur Utama

### 1. 🧭 Kompas Hari Ini & Irama Waktu
- Menampilkan weton hari ini, pasaran aktif, bobot neptu, dan wuku siklus 210 hari Pawukon.
- Jarum arah mata angin kiblat pasaran (*Kiblat Papat Kalima Pancer*).
- Panduan waktu tindakan harian (rekomendasi & laku yang perlu dihindari).

### 2. 📜 Piagam Peta Jiwa & Profil Weton (Cetak / PDF A4 Landscape)
- **Kalkulator Presisi Instan**: Cukup masukkan nama dan tanggal lahir, sistem otomatis menyinkronkan hari lahir, pasaran, neptu, wuku, dan sasi.
- **Piagam Resmi 1 Halaman Penuh (Full Page)**: Desain bingkai ganda keraton beraksen emas yang proporsional dan siap dicetak/disimpan ke PDF.
- **Analisis 4 Dimensi Kosmologis**:
  - *Sadworo (Paringkelan)*: Tungle s.d. Mawulu.
  - *Caturworo (Sosial)*: Sri, Laba, Jaya, Menala.
  - *Triworo (Unsur Alam)*: Pasah (Besi), Beteng (Batu), Kajeng (Kayu).
  - *Dasaworo (Lakon Watak)*: Pandhita s.d. Raksasa.
- **Jadwal Selapanan 1 Tahun**: Menghitung 8 momentum perulangan weton 35 hari ke depan.
- **Modul Kemitraan (Petungan Jodoh & Rekan)**: Rumus sisa bagi 8 tradisi Jawa (*Pegat, Ratu, Jodo, Topo, Tinari, Padu, Sujanan, Pesthi*).

### 3. 📅 Kalender Dinamis 9 Kolom Otentik
- Navigasi tahun fleksibel (2024 s.d. 2030+).
- Tampilan 9 kolom standar buku referensi:
  `Tgl | Hari | Pasaran (Neptu) | Wuku | Sasi | Sadworo | Caturworo | Triworo | Dasaworo`
- Indikator baris otomatis untuk **Hari Ini** (`[🟢 Hari Ini]`).
- Ekspor data mandiri ke format **Excel (.xlsx)**, **CSV**, dan **Cetak PDF**.
- Kartu referensi makna filosofis sasi, wuku, dan unsur kosmis.

### 4. ⚖️ Nilai Etis & Budaya
- Dilengkapi **Pernyataan Etis & Disclaimer Budaya** 2-kolom responsif untuk menjaga integritas nilai luhur falsafah Jawa.

## 🚀 Teknologi yang Digunakan

- **Frontend**: React 18, TypeScript, Vite
- **Styling**: Tailwind CSS, Google Fonts (*Marcellus*, *Cinzel*, *Plus Jakarta Sans*)
- **Icons**: Lucide React
- **Ekspor Data**: SheetJS (`xlsx`)
- **Algoritma**: Universal Julian Day Number (JD) Astronomis Tradisi Jawa

## 💻 Menjalankan Secara Lokal

### Prasyarat
- [Node.js](https://nodejs.org/) (versi 18 ke atas disarankan)
- NPM

### Langkah Menjalankan
```bash
# 1. Masuk ke direktori proyek
cd kalender-pawukon---forecasting-siklus-hidup-jawa

# 2. Pasang dependensi
npm install

# 3. Jalankan server lokal pengembangan
npm run dev
```

Buka peramban Anda dan akses:
👉 `http://localhost:3000`

### Membangun Paket Produksi (Build)
```bash
npm run build
```
Hasil kompilasi siap rilis akan berada di folder `dist/`.
